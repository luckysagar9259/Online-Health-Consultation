# Online Health Consultation Platform
## Project Description

Online Health Consultation Platform is a web-based application that connects patients with doctors for online healthcare consultation.

## Features

### Patient Features
- Patient registration and login
- Patient dashboard
- View patient profile
- Find doctors
- View doctor profiles
- Book appointments
- View appointments and appointment status
- Online consultation
- Chat with doctor
- Video consultation
- Logout

### Doctor Features
- Doctor registration and login
- Doctor dashboard
- Manage doctor profile
- View patient requests
- Accept or reject appointments
- View appointments
- Online consultation
- Chat with patients
- Video consultation
- Logout

## How to Run the Backend

Open the terminal inside the `demo` folder and run:

```powershell

## How to Run the Frontend

1. Open the `Online-Health-consultation` folder in Visual Studio Code.
2. Open `index.html`.
3. Use the VS Code Live Server extension.
4. Open the website in a web browser.
